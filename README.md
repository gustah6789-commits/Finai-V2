# FinAI V2

V2 adiciona cartões, recorrentes, metas, orçamento mensal e análise do assistente.

Para atualizar o GitHub Pages: substitua os arquivos da V2 no repositório `Finai`, mantendo os nomes `index.html`, `manifest.webmanifest` e `sw.js`. A pasta `icons` também deve ser atualizada.

Os dados ficam no armazenamento local do navegador/aparelho. Esta versão ainda não possui conta ou sincronização em nuvem.
